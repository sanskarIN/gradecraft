# Roadmap

## 1.0 — Core product

- [x] Weighted and points-based courses
- [x] Custom assignments/categories/scales
- [x] What-if planning
- [x] GPA calculation
- [x] Charts
- [x] CSV + JSON portability
- [x] Local privacy controls
- [x] PWA/offline shell
- [x] Accessibility baseline

## 1.1 — Refinement

- [x] Editable existing assignments
- [x] Undo action for destructive assignment removal
- [x] Weighted-category target-score solver
- [x] Deployment-base-aware PWA assets and service worker
- [x] Centralized English UI message catalogs for localization readiness
- [x] Safe grading-profile deletion and duplicate-name protection
- [x] Unicode-normalized identity validation and canonical persistence timestamps
- [x] Bounded/conflict-aware CSV import and centralized user-safe transfer errors
- [x] Current-page navigation semantics and dialog focus restoration
- [x] Dedicated maskable PWA icon plus manifest/source regression checks
- [x] Deterministic grade benchmark, CSV fuzz cases, documentation-link checks, and release-version consistency checks
- [ ] Localization packs beyond English
- [ ] Optional semester grouping
- [ ] Real release screenshots and hosted demo link

## 2.0 — Optional advanced capabilities

- [ ] Opt-in encrypted cross-device backup using a user-chosen provider
- [ ] Import mapping UI for arbitrary third-party CSV headers

Roadmap items are proposals, not promises. Privacy-first offline use remains the product baseline.
