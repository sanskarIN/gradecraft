# Privacy Policy

GradeCraft is designed to work without an account or application backend.

## Data stored

Course names, codes, categories, assignment scores, grade scales, preferences, and backup metadata are stored in the browser's Local Storage on the device/profile where GradeCraft runs.

## Data transmission

The GradeCraft application itself does not transmit grade data to a GradeCraft server and does not include analytics or advertising SDKs. Hosting providers and browsers may still process ordinary network metadata when application assets are downloaded.

## Exports and imports

JSON backups and CSV files are processed in the browser. Once exported, those files are controlled by you and by the storage location where you save them.

## Deletion

Settings → **Delete all local data** removes GradeCraft's primary and recovery records from Local Storage. Browser-level backups, synced browser profiles, downloaded exports, or operating-system backups are outside GradeCraft's control.
