# Privacy Policy

GradeCraft is designed to work without an account or application backend.

## Data stored

Course names, codes, categories, assignment scores, grade scales, preferences, and application timestamps are stored in the browser's Local Storage on the device/profile where GradeCraft runs. During normal saves, GradeCraft also keeps one namespaced recovery copy of the previous valid serialized record to recover from a corrupt primary value.

## Data transmission

The GradeCraft application itself does not transmit grade data to a GradeCraft server and does not include analytics or advertising SDKs. Hosting providers and browsers may still process ordinary network metadata when application assets are downloaded. External GitHub and Buy Me a Coffee links are only contacted when you choose to open them.

## Logging

GradeCraft does not intentionally persist an application telemetry log. Diagnostic console events redact sensitive domain/identity keys plus common email and bearer-token patterns. Browser developer tools, browser extensions, operating-system diagnostics, and hosting/runtime tooling remain outside GradeCraft's control.

## Exports and imports

JSON backups and CSV files are processed in the browser. Backup/CSV validation happens locally before imported data enters application state. Once exported, those files are controlled by you and by the storage location where you save them.

## Deletion

Settings → **Delete all local data** removes GradeCraft's primary and recovery records from Local Storage and does not immediately recreate them during the same reset operation. Browser-level backups, synced browser profiles, previously downloaded exports, or operating-system backups are outside GradeCraft's control.
